# COMMA Portfolio

Modern portfolio website built with Next.js, Tailwind CSS and Sanity CMS.

## Stack

- Next.js 15
- React
- Tailwind CSS
- Sanity CMS
- Vercel

## Features

- Fully responsive
- Headless CMS integration
- Dynamic project management
- Modern editorial layout
- Optimized images
- Easy content editing
- Ready for deployment
